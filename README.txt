# Site "Um Date Comigo?" ❤️

Arquivos:
- index.html — estrutura das telas
- style.css — cores, layout, animações e responsividade
- script.js — navegação, botão "NÃO" fugitivo e WhatsApp

## Como usar
Abra o `index.html` em um navegador. No celular, o layout ocupa a tela como um aplicativo.

## WhatsApp
O botão final abre uma conversa para o número configurado no `script.js`:
5592984730368 (Brasil +55, DDD 92).

Se quiser trocar o número depois, procure:
const number='5592984730368';

e substitua pelo número no formato internacional, sem espaços, parênteses ou hífen.
